ctrl + \ toggles on or off

ctrl + ' shuts down

Only works for letters used in Filipino (ex: typing x or q will not convert them into baybayin of "ecks" or "kyu")

valid keyboard inputs (any letter used in filipino) are removed via backspace then replaced with appropriate baybayin character using unicode

zero width spaces are added inbetween modifiers and characters so apps that use graphme clustering don't break it
